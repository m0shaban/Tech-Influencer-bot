# 📘 السيناريو التقني التفصيلي (Technical Scenario) - RoboVAI v3.0

هذا المستند يشرح دورة حياة النظام (System Lifecycle) وتدفق البيانات (Data Flow) في النسخة الحالية الموحدة "Single-Bot Architecture".

---

## 🏗️ 1. المعمارية العامة (Architecture Overview)

النظام يعمل الآن كـ **Single Process Application** (عملية واحدة) على سيرفرات Render.

- **نقطة الدخول (Entry Point):** `unified_bot.py`
- **المحرك (Engine):** مكتبة `python-telegram-bot` باستخدام `JobQueue` للمهام المجدولة و `Polling` للاستجابة للأوامر.
- **قاعدة البيانات (State):** ملفات JSON بسيطة (`seen_posts.json`) لتفادي التكرار.

---

## 🔄 2. دورة التشغيل (Execution Loop)

السيناريو يبدأ تلقائياً عند تشغيل السيرفر. إليك الخطوات التقنية بالتفصيل:

### المرحلة 1: التشغيل الأولي (Initialization)

1.  يقوم `unified_bot.py` بتحميل المتغيرات البيئية (`.env`).
2.  يتم تفعيل `unified_config.py` لتحميل:
    - قائمة المصادر الموحدة (`ALL_FEEDS`).
    - موجه النظام الخاص بالذكاء الاصطناعي (`SYSTEM_PROMPT`).
3.  يتم بناء تطبيق تيليجرام (`ApplicationBuilder`) وربطه بالتوكن.
4.  **الجدولة:** يتم تسجيل وظيفة `scheduled_post` في `JobQueue` لتتكرر كل **3600 ثانية (ساعة)**.

### المرحلة 2: حلقة العمل (The Job Loop)

عندما تحين لحظة التنفيذ (كل ساعة)، يحدث التالي:

#### 1. اختيار المصدر (Feed Selection)

- يستدعي البوت دالة `fetch_random_new_post` من `feed_manager.py`.
- يتم تمرير قائمة المصادر (`ALL_FEEDS`) ويتم عمل **خلط عشوائي (Shuffle)** لها لضمان تنوع الأخبار (مرة ذكاء اصطناعي، مرة برمجة، إلخ).
- يقوم النظام بالمرور على الروابط واحداً تلو الآخر حتى يجد خبراً **جديداً** (غير موجود في `seen_posts.json`).

#### 2. الجلب والتحليل (Fetching & Parsing)

- يستخدم `feedparser` و `requests` لجلب محتوى الـ RSS.
- يقوم باستخراج: العنوان، الملخص، الرابط، والصورة (يحاول استخراج أفضل صورة متاحة عبر `_extract_image`).

#### 3. المعالجة الذكية (AI Processing)

- يتم إرسال البيانات (العنوان + الملخص) إلى `ai_processor.py`.
- يستدعي `Groq API` (نموذج Llama-3-8b-versatile أو غيره).
- **المدخلات:** النص الإنجليزي الخام + `SYSTEM_PROMPT` (الذي يجبره على التحدث كخبير تقني عربي).
- **المخرجات:** نص JSON يحتوي على `telegram_post` (نص المنشور العربي + الإيموجي).

#### 4. إدارة الصور (Image Handling)

- يتم التأكد من وجود صورة صالحة عبر `image_manager.py`.
- إذا لم توجد صورة في الخبر الأصلي، يمكن للنظام (اختيارياً) إنشاء صورة افتراضية (هذه الميزة موجودة كـ fallback).

#### 5. عملية النشر (Publishing)

- **تيليجرام (فوري):**
  - يقوم البوت بإرسال الصورة + النص العربي + الرابط الأصلي إلى `CHANNEL_ID`.
  - عند النجاح، يتم تسجيل الرابط في `seen_posts.json` فوراً "Seen".
- **المنصات الأخرى (Async/Background):**
  - إذا كان `SequentialPublisher` مفعلاً، يتم إنشاء مهمة خلفية (`asyncio.create_task`) لإرسال نفس المحتوى إلى (Discord, Facebook, LinkedIn) بشكل متسلسل لعدم تعطيل البوت الرئيسي.

---

## 🛠️ 3. التعامل مع الأوامر (Event Handling)

بالتوازي مع الجدولة، البوت ينتظر أوامر الأدمن:

- `/start`: رسالة ترحيب (للمستخدمين والليدز).
- `/force`: (للأدمن فقط) يقوم بتجاوز الجدول الزمني وتشغيل دورة "حلقة العمل" فوراً لجلب خبر جديد في الحال.

---

## 🧩 4. المكونات التقنية

| الملف               | الوظيفة                                            |
| :------------------ | :------------------------------------------------- |
| `unified_bot.py`    | المدير العام، يحتوي على `main loop` ومنطق النشر.   |
| `unified_config.py` | مخزن الإعدادات الثابتة (روابط RSS + البرومبت).     |
| `feed_manager.py`   | "الباحث"، مسؤول عن الاتصال بالمواقع وفلترة القديم. |
| `ai_processor.py`   | "المترجم والكاتب"، العقل المدبر للمحتوى.           |
| `image_manager.py`  | مسؤول عن جلب الصور ورفعها (إذا لزم الأمر).         |

---

## 🛡️ 5. معالجة الأخطاء (Error Handling)

- **فشل جلب المصدر:** يتم تجاهل المصدر والانتقال للتالي في القائمة.
- **فشل الـ AI:** يتم طباعة خطأ وعدم النشر (لضمان الجودة).
- **فشل Telegram API:** يتم تسجيل الخطأ (`logging`) ومتابعة العمل (لا يتوقف السيرفر).
- **Render Restart:** السيرفر مصمم ليعمل بلا توقف (`run_polling`)، وفي حال إعادة التشغيل من Render، يبدأ البوت من جديد بشكل طبيعي.

---

## 🚀 الخلاصة

النظام الآن هو **RAG (Retrieval-Augmented Generation) Bot** مبسط:

1.  **Retrieve:** يجلب أخبار RSS.
2.  **Augment:** يضيف سياق "خبير عربي".
3.  **Generate:** يولد محتوى جذاب.
4.  **Distribute:** ينشر على القناة.
