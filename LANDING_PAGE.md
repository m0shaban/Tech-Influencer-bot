# 🎨 RoboVAI Landing Page

## What's This?

A beautiful, professional landing page for your Render web service.

## Features

- ✅ **Responsive Design** - Works perfectly on mobile & desktop
- ✅ **Arabic Support** - Full RTL layout
- ✅ **Modern UI** - Gradient backgrounds, animations, smooth transitions
- ✅ **Bot Information** - Features, stats, and social links
- ✅ **Multiple Endpoints**:
  - `/` - Landing page (HTML)
  - `/health` - Health check (JSON)
  - `/api/status` - Detailed status (JSON)

## How It Looks

The landing page includes:
- 🤖 Bot name and tagline
- 🟢 Live status badge
- 📊 Stats (24/7 uptime, platforms, AI)
- ✨ Feature cards (AI, multi-platform, OG images)
- 🔗 Social media buttons (Telegram channel & group)
- 🛠️ Tech stack information

## URLs

After deployment on Render:
- **Landing Page**: `https://robovai-bot.onrender.com/`
- **Health Check**: `https://robovai-bot.onrender.com/health`
- **API Status**: `https://robovai-bot.onrender.com/api/status`

## For UptimeRobot

Use any of these URLs for monitoring:
- `https://robovai-bot.onrender.com/health` (recommended)
- `https://robovai-bot.onrender.com/` (landing page)

Both will keep your service awake!

## Customization

To customize the landing page, edit: `templates/index.html`

You can change:
- Colors (search for `#667eea` and `#764ba2` for gradients)
- Stats and features
- Social media links
- Text content
