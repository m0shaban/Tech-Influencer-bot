## 💎 القيمة للأعمال (Business Value)

### لماذا RoboVAI؟

في عالم الـ Marketing اليوم، **الاستمرارية (Consistency)** هي العملة الصعبة.

- **بدون RoboVAI:** تحتاج لفريق (كاتب محتوى + باحث + مدير سوشيال ميديا) بتكلفة لا تقل عن $1,000/شهرياً.
- **مع RoboVAI:** تحصل على 50+ منشور يومياً، بجودة "خبير"، وتكلفة تشغيل تقارب **الصفر**.

| **التكلفة**   | $1000+/شهرياً        | $0 (Free Tier)         |

## 🧠 العقل المدبر (The Brain)

يتميز النظام بذكاء اصطناعي "متعدد الشخصيات" (Multi-Persona Engine) يفهم طبيعة كل منصة:

1.  **Telegram (The Friend):** يكتب كصديق خبير يرسل رسالة صوتية أو نصية سريعة. "بص يا صديقي، اللي حصل النهاردة ده..."
2.  **Facebook (The Preacher):** يكتب بأسلوب "الحكيم التقني" الذي يبسط الأمور للعوام. "ناس كتير فاهمة الموضوع غلط، تعالوا نصحح المفاهيم..."
3.  **LinkedIn (The Strategist):** (قريباً) يكتب بأسلوب احترافي يركز على البيزنس والكاريير.
4.  **Twitter/X (The Sniper):** (قريباً) تغريدات قصيرة، حادة، ومثيرة للجدل.

---

## 🚀 المميزات التقنية

- **Smart Scraping:** مراقبة لحظية لأكثر من 50 مصدر عالمي (TechCrunch, TheVerge, OpenAI Blog, etc.).
- **Smart Filtering:** فلترة الأخبار المكررة والضعيفة واختيار "التريند" فقط.
- **Human Simulation:** نظام جدولة ذكي (Smart Scheduler) يحاكي السلوك البشري (ينشر في أوقات الذروة، يتوقف للنوم، يغير فترات النشر).
- **State Persistence:** يتذكر ما نشره، ويحفظ حالته حتى لو تم إعادة تشغيل الخادم.
- **Live Dashboard:** لوحة تحكم لمراقبة الأداء لحظة بلحظة.

## 🛠️ التثبيت والتشغيل

### 1. المتطلبات

- Python 3.11+
- مفتاح API من Google Gemini

### 2. التثبيت المحلي

```bash
git clone https://github.com/m0shaban/RoboVAI.git
cd RoboVAI
pip install -r requirements.txt
```

### 3. إعداد البيئة

قم بإنشاء ملف `.env`:

```env
GEMINI_API_KEY=your_key_here
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHANNEL_ID=@your_channel_id
```

### 4. التشغيل

لتشغيل الناشر الآلي:

```bash
python auto_publisher.py
```

لتشغيل لوحة التحكم:

```bash
streamlit run dashboard.py
```
